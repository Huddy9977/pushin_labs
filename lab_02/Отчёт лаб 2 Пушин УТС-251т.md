Введение
Цель: Изучение синтаксиса и практических возможностей условных операторов (if-elif-else), циклических конструкций (while, for..in) и пользовательских функций (def) в языке Python. Приобретение навыков декомпозиции алгоритмов управления, передачи аргументов и возврата результатов вычислений.
Краткие теоретические сведения:
•	Условный оператор if-elif-else: используется для проверки логических условий и ветвления алгоритма. Конструкция elif позволяет связывать несколько последовательных проверок без добавления лишней вложенности отступов. Блок else выполняется, если ни одно из условий не подтвердилось. Обязательным синтаксическим правилом является использование двоеточия (:) и строгое соблюдение отступов (4 пробела). 
•	Цикл while: выполняет блок выражений до тех пор, пока проверяемое условие истинно (True). Для экстренного выхода из цикла применяется оператор break, а для перехода к следующей итерации — continue. При естественном завершении цикла выполняются команды из необязательного блока else. 
•	Цикл for..in и функция range(): Осуществляет перебор элементов последовательности (списков, строк или диапазонов). Встроенная функция range(start, stop, step) генерирует арифметическую прогрессию чисел, не включая верхнюю границу stop. 
•	Пользовательские функции (def): представляют собой многократно используемые блоки кода с собственным именем. Функция объявляется с помощью ключевого слова def, принимает параметры и возвращает результаты вычислений оператором return. Строки документации docstrings (в тройных кавычках) размещаются сразу после заголовка функции для описания ее назначения.

 
Практическая часть
Условие: написать функцию filter_adc_signal(raw_data), отбраковывающую значения 0 и 1023 как сбои с помощью continue и вычисляющую среднее значение фильтрованного сигнала. Функция возвращает отфильтрованный список и среднее. Вариант 13
Код:
def filter_adc_signal(raw_data):
    filtered_raw = [] #пустой список, который используеся для отсортированных значений
    for i in raw_data: #цикл перебирает значения в списке
        if i == 1023 or i == 0: #проверка равно ли число внутри списка 1023 или 0
            continue 
        filtered_raw.append(i) #добавляем отсортированные значения
  
    return filtered_raw #возвращаем список

raw_data = [] #пустой список, в котором будут неотсортированные значения
a = int(input('Сколько значений в вашем списке?')) #спрашиваем у пользователя количество значений
for i in range(a): #цикл, позволяющий вносить пользователю значения в список
    raw_data.append(int(input(f"Введите значение {i+1} ")))

print(raw_data) #вывод списка для проверки
filtered = filter_adc_signal(raw_data) #присваиваем новой переменной значения из функции
print(f'Отсортиванный список {filtered}') #вывод отфильтрованного списка из функции
print(f'Среднее значение {sum(filtered)/len(filtered)}') #вывод среднего значения отфильтрованного списка

Заключение
В ходе работы освоены базовые управляющие конструкции Python: условные операторы (if elif else), циклы (while, for..in) и пользовательские функции (def). Отработаны приёмы декомпозиции алгоритма, передачи аргументов и возврата результатов.
Условные операторы позволили реализовать проверку пороговых значений и выстроить логику ветвления — разные действия в зависимости от состояния данных. Циклы обеспечили обработку произвольного набора значений по единому шаблону, а также организацию многократного ввода данных.
Выделение логики в функции сделало алгоритм модульным: каждый блок решал отдельную задачу, при этом оставался универсальным за счёт передачи аргументов и возврата результатов через return.
Таким образом, закреплены навыки структурирования алгоритма и грамотного применения ключевых конструкций языка для обработки данных.
