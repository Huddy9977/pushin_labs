## Краткие теоретические сведения: 
Модульная архитектура: модуль в Python — это отдельный файл .py. Для подключения используется import или from ... import .... Чтобы код выполнялся только при прямом запуске файла, применяется проверка `if __name__ == '__main__':`. Системный модуль sys и список sys.argv позволяют передавать скрипту параметры из командной строки.
### Базовые структуры данных:
- Списки (list): упорядоченные изменяемые массивы. Методы: `append()`, `sort()`, `pop()`.
- Кортежи (tuple): упорядоченные неизменяемые последовательности. Используются для защиты данных и возврата нескольких значений из функции.
- Словари (dict): ассоциативные массивы «ключ: значение». Ключи уникальны.
- Множества (set): неупорядоченные коллекции уникальных элементов. Поддерживают операции: объединение |, пересечение &, разность -.
Операции срезов: синтаксис [start:stop:step]. start — начало (включительно), stop — конец (не включительно), step — шаг. Отрицательные индексы отсчитываются с конца, а шаг -1 (например, [::-1]) разворачивает последовательность в обратном порядке.
 
# Практическая часть
*Вариант 13. Весовой контроль конвейерной линии упаковки Физический процесс / инженерное явление: на фасовочной линии пищевого комбината тензометрические датчики взвешивают проходящие упаковки. Продукты с весом вне нормативного допуска забраковываются, а для контроля качества отбирается каждая N-я упаковка.* 
**Задачи модуля (variant_mod.py):** 
1) `reject_defective_items(weight_list, min_w=98.0, max_w=102.0)` — разделяет список весов на годные и бракованные; 
2) `get_weight_distribution(weight_list)` — возвращает словарь с подсчетом количества легких, нормальных и тяжелых упаковок; 
3) `get_sample_pack(weight_list, step=3)` — формирует контрольную выборку каждой step-й детали срезом [::step]. 
**Требования к программе main.py:** 
- Считать шаг контроля step из `sys.argv[1]` (дефолт 3). 
- Задать массив измерений веса упаковок, выполнить отбраковку и получить выборочную контрольную партию.
## Код для программы variant_mod.py:
```
def reject_defective_items(weight_list,min_w=98.0,max_w=102.2):
    filtered=[]
    wrong=[]
    
    for i in weight_list:
        if min_w<=i<=max_w:
            filtered.append(i)
        else:
            wrong.append(i)
            continue
    return filtered, wrong

def get_weight_distribution(weight_list,min_w=98.0,max_w=102.0):
    weight_dic = {
        "легкие":0,
        "нормальные":0,
        "тяжелые":0
    }
    for i in weight_list:
        if i < min_w: weight_dic["легкие"]+=1
        if min_w <= i <=max_w: weight_dic["нормальные"]+=1
        else: weight_dic["тяжелые"]+=1
    return weight_dic
def get_sample_pack(weight_list, step):
    return weight_list[::step]
```

import sys

if __name__ == "__main__":
