## Краткие теоретические сведения:
Язык Python является интерпретируемым. При первом запуске код транслируется в промежуточный байт-код и выполняется виртуальной машиной. Переменные представляют собой ссылки (имена), связанные с объектами в динамической памяти. Отступы (ровно 4 пробела) обязательны и служат для группировки блоков кода. Метод format() позволяет выполнять форматирование в соответствии со спецификацией PEP 3101.
Например, выражение *'{0:.3f}'.format(pi)* форматирует вещественное число с точностью до трех знаков после запятой. Вместо метода format() можно использовать f-строки.
 
# Практическая часть
**Условие задачи: напишите скрипт**, вычисляющий физическую величину по формуле. Все переменные должны быть динамически привязаны к значениям. Вывод результата осуществить с округлением вещественной части до 4 знаков после запятой. Вариант 13

## Код задачи:
```
k = float(input("Введите значение k: ")) #создаем переменные типа float для записи дробных чисел  
s = float(input("Введите значение s: "))
T1 = float(input("Введите значение T1: "))
T2 = float(input("Введите значение T2: "))
d = float(input("Введите значение d: "))
Q = k*s*(T1-T2)/d #записываем формулу
print(f"Тепловые потери стены Q = {Q:.4f}") #выводим Q и сокращаем до 4 знаков после запятой с помощью f строки
``` 
## Результат:
```
Введите значение k: 0.14
Введите значение s: 24.5
Введите значение T1: 22
Введите значение T2: -15
Введите значение d: 0.4
Тепловые потери стены Q = 317.2750

```
