Введение
Цель работы: изучить базовые концепции контроля версий, приобрести практические навыки установки и настройки Git, создания локальных и удаленных репозиториев, а также организации структуры для хранения последующих лабораторных работ по программированию.
Краткие теоретические сведения Git — это распределенная система контроля версий. Она позволяет фиксировать изменения в файлах (делать «снимки» проекта — коммиты), возвращаться к предыдущим версиям кода и безопасно вести разработку. 
Локальный репозиторий — скрытая папка .git на вашем компьютере, где хранится вся история изменений вашего проекта. 
Удаленный репозиторий — копия вашего проекта, размещенная на сервере в сети (в данном случае на GitHub). Она служит для резервного копирования и демонстрации кода. 
Коммит (Commit) — сохраненное состояние проекта с уникальным идентификатором. Каждое сохранение обязательно должно сопровождаться осмысленным описанием выполненной работы
 
Практическая часть
1.	Установка программного обеспечения
Скачивание Git: 
Выполняем загрузку установочного файла с официального сайта gitscm.com
Запускаем установку, используя настройки по умолчанию
Проверяем корректность установки через терминал командой git --version
2.	Настройка параметров Git
Конфигурация учётной записи:

git config --global user.name "Имя группы"
git config --global user.email email@example.com

Важные моменты: используем email, привязанный к аккаунту GitHub
3.	Создание рабочей структуры
Формирование корневой директории:

mkdir programming-labs
cd programming-labs

Инициализация репозитория:

git init

Организация первой лабораторной:

mkdir lab_01

4.	Подготовка к первому коммиту
Проверка состояния репозитория:

git status

Индексация файлов:

git add .

Сохранение изменений:

git commit -m "Initial commit: создание структуры проекта"

5.	Работа с GitHub
Создание репозитория:
Регистрируемся/входим в GitHub
Создаём новый репозиторий с именем programming-labs
Оставляем настройки пустыми
Синхронизация с локальным репозиторием:

git remote add origin https://github.com/НИК/programming-labs.git
git branch -M main
git push -u origin main
